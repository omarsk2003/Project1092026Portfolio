# Omar AlSmadi Portfolio

A responsive personal portfolio website for **Omar AlSmadi**, a fresh graduate and Full Stack Developer.

The website presents my education, technical skills, soft skills, projects, experience, references, and contact information in a simple and professional design.

## Technologies

* HTML5
* CSS3
* Bootstrap 5

## Features

* Responsive design for desktop, tablet, and mobile devices
* Navigation bar with links to all sections
* About Me section
* Experience section
* Qualification and certificates section
* Technical and soft skills section
* Projects section
* References section
* Contact information in the footer
* Responsive mobile navigation menu
* Certificate viewing link
* Links to GitHub and LinkedIn profiles
